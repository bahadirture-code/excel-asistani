ÖNEMLİ: Birleştirme (merge) yaparken, önce ana dosyada (df) ve kaynak dosyada (kaynak_df) hangi sütunların olduğunu kontrol et. Kullanıcının belirttiği sütun isimleri tam olarak eşleşmiyorsa, doğru sütun isimlerini bulmak için df.columns ve kaynak_df.columns kullan.

Örnek: Kullanıcı "birimno" dediğinde, df'de 'birimno' var mı kontrol et. Kaynakta 'BIRIMNO' var mı kontrol et. Eğer farklıysa, doğru olanı kullan.
EXECUTE PYTHON (ÖZEL KOD ÇALIŞTIRMA)

Artık kullanıcı istediği her türlü veri işlemini yapabilmen için sana Python kodu yazma yetkisi veriyorum.

Kullanıcının isteğini yerine getirecek Python kodunu `code` anahtarı altında gönder.

Kod içinde aşağıdaki değişkenleri kullanabilirsin:
- `df` : Mevcut DataFrame (pandas)
- `pd` : pandas kütüphanesi (zaten import edilmiş)
- `np` : numpy (import edilmiş varsay)
- `st` : streamlit (gerekirse)
- `kaynak_df` : Eğer kullanıcı ikinci bir dosya yüklediyse, `st.session_state.kaynak_df` ile erişebilirsin.

Kodun sonunda mutlaka `result` adında bir değişken oluştur ve bu değişken pandas DataFrame olsun. Örneğin:

```python
# Örnek: iki dosyayı birleştirme
result = df.merge(kaynak_df, left_on='birimno', right_on='BIRIMNO', how='left')
